## Goal
Move Merlin intake action cards, decision state, apply state, duplicate/replacement warnings, and apply audit metadata from in-memory runtime state to durable persistence so review/apply survives restarts.

- src/merlin/intake/actionCardQueue.ts

## Durable Model Implemented
SQLite-backed durable store `merlin_intake_action_cards` (created/managed in `actionCardQueue.ts`) with:
- identity/payload fields:
  - id, batch_id, type, title, entity_type, confidence
  - source_file_ids_json, extracted_fields_json, missing_fields_json
  - existing_entity_match_json, recommended_action
- warning/conflict fields:
  - duplicate_warnings_json, conflict_warnings_json, replacement_candidate_json
- decision state fields:
  - decision_state, decision_by, decision_at, decision_reason
- apply state fields:
  - apply_state, applied_by, applied_at, apply_result_json, apply_error
- timestamps:
  - created_at, updated_at

Defaults:
- decisionState: pending
- applyState: not_applied

Indexes:
- idx_merlin_action_cards_batch
- idx_merlin_action_cards_decision_state
- idx_merlin_action_cards_apply_state

## Persistence Behavior
- Preview-generated action cards are persisted/upserted deterministically by card `id`.
- Re-running preview for same batch does not create duplicate rows.
- Regeneration refreshes evidence payload fields while preserving existing decision/apply state.
- Duplicate-like cards remain visible (not suppressed) and keep warning metadata.
- Dry-run, decision, and apply endpoints read durable card records.
- Apply endpoint persists applyState/applyResult/applyError and remains idempotent after restart.

## Duplicate/Conflict/Replacement Handling
Canonical rule preserved:
- Duplicates are evidence conflicts, not trash.

Implemented behavior:
- duplicateWarnings/conflictWarnings/replacementCandidate carried on cards and responses.
- duplicate-looking create cards remain in queue.
- apply requires explicit duplicate override (`allowDuplicateCreate`) for duplicate-like create cards.
- no silent suppression/delete/hide of duplicate-like cards.
