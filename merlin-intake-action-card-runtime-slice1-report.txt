Matching behavior
- Uses existing draft matching results from preview pipeline.
- If existing entity match is present, cards prefer update_existing_profile.
- Low-identity/low-signal evidence yields defer_unclassified.
- Missing required fields yields request_missing_info.

Consolidation behavior
- Multiple screenshots for one truck produce a single draft card when clustering merges evidence.
- Menu + logo + profile evidence can consolidate into one action card with multiple sourceFileIds.

Backward compatibility
- Existing preview response fields remain intact (evidenceFiles, clusters, drafts, mergeAssist, publishPlan, etc.).
- actionCards is additive only.
