Endpoint behavior

  - POST /api/merlin/intake/upload-intents/:uploadId/files
  - POST /api/merlin/intake/upload-intents/:uploadId/route
  - POST /api/merlin/intake/upload-intents/:uploadId/preview
- Creation validates brand/actionId/actorScope/entityType through registry.
- Invalid/unregistered action returns INVALID_INTENT.
- Intent creation snapshots allowed/forbidden field paths from adapter action.
- Route uses Merlin router (not product-specific file processor).
- Preview returns draft packet only; no apply endpoint added.
- mutationAllowed:false and implementationAllowed:false remain enforced through this slice.

Adapter boundary explanation
- Product adapters define only context/action metadata:
  - action definitions
  - allowed/forbidden field paths
  - actor/entity compatibility
  - preview/approval requirements
- Product adapters do not perform OCR/routing/publishing/live mutation.
- Merlin core owns routing + preview generation + safety holds.

Preview/edit gate behavior
- Every upload intent remains preview-gated.
- Output stops at PREVIEW_READY / HELD_FOR_REVIEW / ERROR.
- implementationAllowed remains false.
- No role (including staff/admin) bypasses preview.

Routing conflict behavior
- Intent-evidence mismatch held as INTENT_EVIDENCE_CONFLICT.
- Cross-domain mismatch held as AMBIGUOUS_OR_WRONG_DOMAIN.
- Low-confidence/ambiguous evidence held.
- No silent cross-brand routing.
