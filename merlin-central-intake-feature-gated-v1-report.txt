- POST /api/merlin/intake/upload-intents/:uploadId/files attaches files only to valid intents.
- POST /api/merlin/intake/upload-intents/:uploadId/route returns routing decisions.
- POST /api/merlin/intake/upload-intents/:uploadId/preview returns preview-only packet.
- GET /api/merlin/intake/actions?brand=MEALSCOUT returns registered actions.

- Global disabled => MERLIN_INTAKE_DISABLED

- No intent creation, routing, or preview execution while disabled.
