## Backend Endpoints Added
1. `GET /api/mealscout/intake/affiliates/dashboard`
- role-gated (`admin/super-admin/operator/staff`)
- returns affiliate-level metrics:
  - batch/file/card counts
  - approved/apply/create/update counts
  - notification/open/claim/review counts
  - payout-ready/review state counts
- `mutationAllowed:false`
- no payout math

2. `GET /api/mealscout/intake/affiliates/:affiliateId/audit-items`
- role-gated
- returns card-level affiliate audit rows with:
  - decision/apply/notification states
  - duplicate/conflict/replacement warnings
  - affiliateAuditState/payoutReady
  - qualified/disqualifying signals
- supports unknown/null affiliate view via `unknown` route key
- `mutationAllowed:false`

3. `PATCH /api/mealscout/intake/action-cards/:cardId/affiliate-audit`
- role-gated
- updates affiliate audit metadata only
- derives and stores qualified/disqualifying signals + evidence score
- enforces guards:
  - payoutReady requires `affiliateAuditState=approved_for_payout_review`
  - unresolved duplicate/conflict/replacement blocks payoutReady unless explicit override
  - unapplied cards block payoutReady unless explicit override
  - no open/claim/review engagement requires operator reason for approved state
- `mutationAllowed:false`
