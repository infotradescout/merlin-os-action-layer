## Backend Endpoint Added
### `POST /api/mealscout/intake/drive/sync-and-process`
- Role-gated: `admin/super-admin/operator/staff`
- Behavior:
  - Runs Drive sync detection for supported files
  - Creates new queued batch for newly detected files
  - Processes only `detected/queued` batches
  - Builds clusters/drafts/action cards via existing flow
  - Persists cards in durable ledger
  - Propagates attribution metadata
- Safety:
  - `mutationAllowed:false`
  - no card apply/approval
  - no notification send
  - no Drive cleanup/delete/archive/suppress
  - no TradeScout behavior
- Response includes:
  - `status`
  - `detectedFileCount`
  - `newBatchCount`
  - `processedBatchCount`
  - `cardsCreatedCount`
  - `cardsReadyCount`
  - `failedBatchCount`
  - `duplicateFileWarnings`
  - `batches`
  - `errors`
  - `mutationAllowed:false`
